# 自动更新文章最后修改时间
根目录配置hugo.yaml
```
frontmatter:
  lastmod: ['lastmod', ':git', ':fileModTime', ':defalut']
  
```
`lastmod`：文章里 lastmod 字段
`:git`：git 文件提交修改时间
`:fileModTime`：文件修改时间
`:defalut`：默认时间
# 加入字数统计
主题文件里
layouts\partials\article\components\details.html
注释内是原代码
```html
        {{ if $showReadingTime }}
            <div>
                {{ partial "helper/icon" "clock" }}
                <time class="article-words"> <!-- <time class="article-time--reading"> -->
                    {{.WordCount}} 字 <!--{{ T "article.readingTime" .ReadingTime }} -->
                </time>
            </div>
        {{ end }}
    </footer>
    {{ end }}
```
# 更新侧边栏icon
在主题文件夹中\assets\icons\
放svg格式icon（比如下面的github.svg，主题自带了个brand-github.svg也可以用）
```
    social:
        - identifier: github
          name: GitHub
          url: https://github.com/hubojing
          weight: 1
          params:
              icon: github
```
